# Release 0.1.5

稳定版本：聚焦可靠性、电池体验与 WiFi 稳定性。

## 亮点

- **RTC 实时收音**：`AT+START=rtc` 通过 BLE 实时收听设备麦克风（配套 App 收听工具）。
- **工厂序列号**：`AT+SN` 一次性写入产品序列号，`AT+SN?` 返回设备 MAC + SN；恢复出厂不清除。
- **存储按需清理**：新增 `AT+GC` 命令，一键回收空会话残留与已同步会话，不碰未同步录音。
- **WiFi 体验**：开关 WiFi 期间按键与界面保持响应；启动慢时不再误报失败。
- **电池**：电量显示充电上升、放电只降（不再"越放越多"）；低电量自动停止录音并保护性锁定，充电恢复。
- **关机可靠性**：修复电池状态下偶发无法关机的问题；关机不再意外自行开机。
- **时间戳**：修复长时间待机后录音时间戳错误的问题；`AT+TIME?` 新增开机恢复标记与运行时长，便于诊断。

## 升级说明

- 支持 App OTA / USB 串口 DFU / J-Link 全量烧录三种升级方式。
- 升级后首次开机建议连接一次 App 同步时间。
- 升级后首次开机电量会重新校准，属正常现象。
