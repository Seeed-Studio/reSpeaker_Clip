# Release 0.1.5

Stability release focused on reliability, battery experience, and WiFi robustness.

## Highlights

- **RTC live listening**: `AT+START=rtc` streams the device microphone live over BLE (companion listening tool included in the SDK).
- **Factory serial number**: `AT+SN` writes a one-time product serial; `AT+SN?` returns device MAC + SN. Survives factory reset.
- **On-demand storage cleanup**: new `AT+GC` command reclaims empty session leftovers and already-synced sessions; unsynced recordings are never touched.
- **WiFi experience**: buttons and UI stay responsive while WiFi turns on; slow bring-up no longer reports a false failure.
- **Battery**: percentage now rises only while charging and never climbs while discharging; recording auto-stops and locks out at critical battery, and recovers on charge.
- **Power-off reliability**: fixed an occasional refusal to power off on battery, and devices no longer power themselves back on after shutdown.
- **Timestamps**: fixed recording timestamps drifting wrong after long standby; `AT+TIME?` now reports a restore flag and uptime for easy diagnosis.

## Upgrade notes

- Upgrade via app OTA, USB serial DFU, or J-Link full image.
- After upgrading, connect the app once to re-sync the clock.
- The first boot after upgrade re-calibrates the battery gauge — expected behavior.
